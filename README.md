# Slovenčina A1 — тренажёр словацкого для курса

Бесплатный сайт для одногруппников: слова, фразы и грамматика всех 6 уроков учебника
«Tri, dva, jeden – slovenčina» (A1, Univerzita Komenského). Похож на Duolingo: занятия по темам,
интервальное повторение, серия дней, опыт, достижения, рейтинг курса.

## Что внутри

- **677 слов в 46 темах** (уроки 1–6), переводы на русский и английский.
- **Задания:** новое слово → выбор перевода → выбор по-словацки → на слух → ввод с клавиатуры
  (кнопки á ä č ď é í ĺ ľ ň ó ô ŕ š ť ú ý ž) → найти пары → собрать предложение.
  Ошибки возвращаются в конец занятия.
- **21 грамматический тренажёр** по учебнику: byť, род, aký/aká/aké, притяжательные, числа,
  спряжение, модальные глаголы, rád/rada, время, цены, винительный падеж, будущее,
  повелительное, прошедшее, множественное число, dvaja/dva/dve, страны.
- **Шпаргалки** — таблицы по каждому уроку.
- **Повторение** по системе Лейтнера: слово возвращается через 1, 2, 4, 7, 15, 30, 60 дней.
- **Словарь** с поиском (можно без диакритики: «kos» найдёт «kôš»).
- **Озвучка** — встроенный голос браузера, только словацкий (`sk-SK`). Чешский голос не
  подставляется никогда. Если словацкого голоса нет — задания на слух пропускаются.
  Голос обычно есть в Chrome на Android и в Microsoft Edge.

## Как не потерять прогресс

1. Прогресс **всегда** сохраняется в браузере, плюс запасная копия на случай сбоя.
2. С аккаунтом (ник + пароль) — ещё и **в облаке** (Firebase). Можно заходить с телефона и
   компьютера. Копии объединяются без потерь: по каждому слову берётся более свежая запись,
   опыт по дням — максимум. Сохранение идёт через транзакцию, поэтому два устройства не
   затирают друг друга.
3. Прогресс, набранный без аккаунта, при первом входе переносится в аккаунт.
4. В профиле есть **«Скачать копию прогресса»** (файл .json) и **«Загрузить копию»**.

## Запуск на своём компьютере

```bash
python -m http.server 8080
```

Открыть http://localhost:8080. Открывать `index.html` двойным кликом нельзя: модули JS
по `file://` не работают.

## Облако (Firebase): один раз, примерно 10 минут

Пока `js/firebase-config.js` пустой, сайт работает без аккаунтов (только локально).

1. Зайди на https://console.firebase.google.com, нажми **Create a project**. Google Analytics можно выключить.
2. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable.**
3. **Build → Firestore Database → Create database** → регион `eur3 (europe-west)` → **production mode**.
4. Вкладка **Rules** → вставь содержимое файла `firestore.rules` → **Publish**.
5. ⚙️ **Project settings → General → Your apps → значок `</>` (Web)** → имя любое → **Register app**.
   Скопируй объект `firebaseConfig` в `js/firebase-config.js` вместо `null`.
6. **Authentication → Settings → Authorized domains** → добавь домен сайта
   (например `твой-ник.github.io`). `localhost` там уже есть.

Конфиг Firebase — не секрет, он всегда виден в браузере. Данные защищают правила из
`firestore.rules`: каждый ученик читает и пишет только свой прогресс.

Бесплатного тарифа Spark хватит с огромным запасом: курсу из 30 человек нужно примерно
3–5 тысяч операций в день при лимите 50 тысяч.

### Вход по нику — как это устроено

Ник превращается во внутреннюю «почту» `nick@slovencina-a1.app`, поэтому настоящий e-mail
не нужен. Минус: **пароль по почте не восстановить**. Если кто-то забыл пароль — удали
его в Firebase → Authentication, пусть зарегистрируется заново (прогресс, если был только
в облаке, придётся перенести вручную через Firestore). Кто хочет восстановление — пусть
регистрируется с настоящим e-mail вместо ника.

## Выкладка на GitHub Pages (бесплатно)

1. Создай репозиторий на GitHub и залей туда эту папку.
2. **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.**
3. Через минуту сайт будет на `https://<ник>.github.io/<репозиторий>/`.
4. Добавь этот домен в Firebase → Authorized domains (шаг 6 выше).

После изменений сайта поменяй версию `CACHE` в `sw.js` (например `slovencina-v2`),
иначе у учеников может остаться старая версия из кэша.

## Как добавить или исправить слова

Всё в `js/data.js`. Одно слово — одна строка:

```
kuchár | повар | cook | m fem=kuchárka
```

словацкий | русский | английский | метки (род `m/f/n/pl`, `fem=` женская форма,
`opp=` антоним, `alt=` второй правильный вариант).

После правки запусти проверку — она ищет чешские буквы (ř, ů, ě), дубли и пустые переводы,
а заодно прогоняет все тренажёры:

```bash
node tools/check-data.mjs
```

Тест объединения прогресса: `node tools/test-merge.mjs`.

## Файлы

| Файл | Что делает |
|---|---|
| `js/data.js` | словарь и предложения по урокам |
| `js/grammar.js` | тренажёры грамматики и шпаргалки |
| `js/store.js` | прогресс, интервальное повторение, опыт, серия, достижения |
| `js/cloud.js` | аккаунты и сохранение в Firebase |
| `js/session.js` | сборка и показ занятий |
| `js/app.js` | экраны и навигация |
| `js/i18n.js` | тексты интерфейса (RU/EN) |
| `js/speech.js` | озвучка и звуки |
| `firestore.rules` | правила доступа к базе |
| `sw.js` | офлайн-режим и установка на телефон |

## Важно

- PDF учебника в репозиторий **не класть**: он защищён авторским правом. На сайте —
  только списки слов и короткие учебные предложения.
- Рейтинг курса можно накрутить, если сильно захотеть: опыт считается в браузере.
  Для учебного рейтинга это не страшно.
